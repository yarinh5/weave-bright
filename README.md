# Elevate Systems

✅ PROMPT ל-Lovable (להעתקה מלאה)




Role & Goal
You are a senior product designer and full-stack engineer.
Build a high-end, modern, conversion-focused landing page for a tech agency that builds:
	•	Automated websites
	•	Business automations
	•	Custom SaaS systems
	•	AI agents
	•	CRM systems




The goal of the page is to look premium, futuristic, and professional, and to convert visitors into leads.




⸻




🧱 Structure & Sections
	1.	Hero Section




	•	Large bold headline:
“We Build Automated Systems That Run Your Business”
	•	Sub-headline explaining:
“Websites, AI agents, CRM systems and SaaS platforms — built to scale”
	•	Primary CTA button: “Book a Free Strategy Call”
	•	Secondary CTA: “See How It Works”
	•	Animated background (subtle gradient, particles, or motion blur)
	•	Smooth entrance animations on load




	2.	What We Build (Services Section)
Create cards with icons and hover animations:




	•	Automated Websites
	•	Business Automations (Make / n8n / APIs)
	•	Custom SaaS Platforms
	•	AI Agents & AI Workflows
	•	CRM & Lead Management Systems




Each card should have:
	•	Title
	•	Short 1-line description
	•	Subtle hover / motion effect




	3.	How It Works
A 3-step or 4-step process section:
	4.	Strategy & Architecture
	5.	System Design
	6.	Development & Automation
	7.	Launch & Scale




Each step with:
	•	Icon or number
	•	Short explanation
	•	Scroll animation




	4.	Why Choose Us
Modern comparison / highlight section:




	•	Fast delivery
	•	Fully custom systems
	•	Scalable architecture
	•	Automation-first mindset
	•	Built for real businesses




Use animated separators or micro-interactions.
	5.	Technology Stack
Logos or text badges:




	•	React / Next.js
	•	Node.js
	•	PostgreSQL
	•	Supabase
	•	Make / n8n
	•	AI APIs (OpenAI-style)




Add soft motion or fade-in animations.
	6.	Call To Action Section
Large centered CTA:
“Ready to automate your business?”
Button: “Start Now”
Background with gradient + animation.
	7.	Footer




	•	Company name placeholder
	•	Contact email placeholder
	•	Simple minimal footer design




⸻




🎨 Design & Style
	•	Dark theme
	•	Modern gradients (purple / blue / neon accents)
	•	Glassmorphism / soft shadows
	•	Rounded cards
	•	Premium SaaS look (Stripe / Linear / Vercel inspired)
	•	Clean typography (Inter / similar)
	•	Mobile-first responsive layout




⸻




⚙️ Technical Requirements
	•	Generate clean, readable code
	•	Use modern React components if possible
	•	Separate components clearly
	•	Avoid hard-coded business data (use placeholders)
	•	Make the structure easy to extend manually later
	•	Add comments explaining sections
	•	Optimize for performance




⸻




✨ Animations
	•	Smooth page load animations
	•	Hover animations on cards and buttons
	•	Scroll-based reveal animations
	•	No heavy or laggy effects




⸻




🧠 Important Notes
	•	This is the initial version of the project
	•	Code quality and structure are important
	•	Focus on professional, enterprise-grade appearance
	•	No generic website builder look
